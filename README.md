##  Features

- **Visual CC Viewer:** See all your CC with thumbnails and sort them by name or date.
- **CC Merging:** Combine your `.package` and `.sims3pack` CC into fewer files to reduce loading times with a single click.
- **Smart Filtering:** Filter your CC by category (Hair, Clothing, Build/Buy, Sliders, etc.) with more coming soon.
- **Configurations:** Create different configurations (mod profiles) and switch between them seamlessly.
